# Кольца и Орбиты

Две музыкальные игры, которые работают в браузере, на Windows и на Android.

- **Кольца.** Шарик заперт внутри сотен радужных колец, через которые идёт прямой проход. Пролетишь в него — кольцо разлетается, а следующие придвигаются ближе. Можно поставить свою музыку: внутри колец она звучит приглушённо и с каждым разбитым кольцом становится чище.
- **Орбиты.** Светящаяся стрелка обходит неподвижные кольца и зажигает на них ноты. Каждое кольцо — отдельная партия музыки, и с каждым новым кольцом в трек добавляется деталь. Если загрузить свой mp3, ноты встанут ровно туда, где они звучат в песне.

Версии для Windows (exe) и Android (apk) скачиваются на сайте игр, только для подписчиков.

## Сайт

В папке [`site/`](site/README.md) лежит сайт игр для России. Пробный период — 3 дня бесплатно, «Месяц онлайн» стоит 329 ₽, «Навсегда» с правом скачивания — 5000 ₽. Оплата через ЮMoney или переводом на карту, есть закрытая админка. Установка на сервер только из терминала:

```bash
git clone https://github.com/Anonymouslol411/kolca-orbity.git
cd kolca-orbity/site
sudo bash manage.sh install
```

## Состав репозитория

- `web/kolca/index.html`, `web/orbity/index.html` — сами игры, каждая в одном HTML-файле.
- `site/` — сайт: Flask, SQLite, Docker и Caddy (Caddy сам выпускает HTTPS-сертификат).
