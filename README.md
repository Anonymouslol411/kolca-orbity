# Кольца и Орбиты

Две музыкальные игры, которые работают в браузере, на Windows и на Android.

- **Кольца.** Шарик заперт внутри сотен радужных колец. Через кольца идёт прямой проход. Пролетишь в него — кольцо разлетается, и следующие придвигаются ближе. Можно поставить свою музыку: внутри колец она звучит приглушённо, а с каждым разбитым кольцом становится чище.
- **Орбиты.** Светящаяся стрелка обходит неподвижные кольца и зажигает на них ноты. Каждое кольцо — отдельная партия музыки: с каждым новым кольцом добавляется деталь. С вашим mp3 ноты стоят там, где они звучат в песне.

## Скачать

Готовые файлы лежат в разделе **Releases** справа:

| Файл | Для чего |
|---|---|
| `Kolca.exe`, `Orbity.exe` | Windows: просто запустить, установка не нужна |
| `Kolca.apk`, `Orbity.apk` | Android: открыть файл и разрешить установку из неизвестных источников |

## Как это собирается

Файлы собираются автоматически (GitHub Actions, `.github/workflows/build.yml`) после каждого изменения в ветке `main`.

- `web/kolca/index.html`, `web/orbity/index.html` — сами игры, это одиночные HTML-файлы.
- `desktop/` — оболочка для Windows на Electron.
- `android/` — оболочка для Android на WebView. Собрать вручную: `gradle assembleDebug -Pgame=kolca`.
- `tools/make_icons.py` — рисует иконки во время сборки.

APK подписан отладочным ключом. Его можно ставить на телефон, но для Google Play нужна отдельная подпись.
