# Сайт «Kolca & Orbity»

Сайт игр «Кольца» и «Орбиты» для России: регистрация, оплата в рублях и закрытая админка.

| Тариф | Цена | Что даёт |
|---|---|---|
| Пробный период | бесплатно | 3 дня игры онлайн сразу после регистрации, карта не нужна |
| Месяц онлайн | 329 ₽ один раз | 30 дней игры в браузере, без автопродления |
| **Навсегда** | **5000 ₽ один раз** | игры онлайн без срока и скачивание exe и apk |

Цены меняются в `.env` (`PRICE_MONTH`, `PRICE_FOREVER`). Если поставить `PRICE_MONTH=0`, месячный тариф пропадёт с сайта.

**Оплата:**
- **ЮMoney** — кошелёк Яндекса для физлица, бесплатный. Покупатель платит картой или кошельком, сервер сам проверяет поступление через API ЮMoney, и доступ открывается автоматически.
- **Перевод на карту** — запасной вариант. Покупатель переводит деньги и указывает код. Вы сверяете поступление в банке и нажимаете «Подтвердить» в админке.
- **Баланс аккаунта** — его начисляете вы в админке, и покупатель может заплатить с него.

Сайт открывается на русском, переключатель языка (ещё 8 языков) находится вверху.

## Установка: только терминал

Нужен сервер с Ubuntu 20.04 или новее. Домен не обязателен: если оставить его пустым, сайт будет работать по IP сервера (`http://IP`). Свой домен или бесплатный `имя.duckdns.org` можно подключить позже, и тогда появится HTTPS.

```bash
git clone https://github.com/Anonymouslol411/kolca-orbity.git
cd kolca-orbity/site
sudo bash manage.sh install
```

Скрипт сам:
1. поставит Docker;
2. спросит домен (если оставить пустым, сайт будет работать по IP), цены, данные ЮMoney (кошелёк, client_id и Redirect URI приложения) и номер карты (всё можно пропустить и задать позже командой `config`);
3. сгенерирует секретный ключ и **секретный адрес админки**;
4. включит фаервол (SSH, 80 и 443) и автообновления безопасности Ubuntu;
5. соберёт и запустит сайт, а HTTPS-сертификат выпустится автоматически;
6. попросит придумать **пароль администратора** (от 12 символов);
7. подключит API ЮMoney: откройте ссылку, разрешите доступ и вставьте код;
8. покажет адрес сайта и адрес админки.

## Команды

Все команды выполняются в папке `kolca-orbity/site`:

```bash
sudo bash manage.sh admin-url            # адрес админки
sudo bash manage.sh duckdns              # подключить бесплатный адрес имя.duckdns.org
sudo bash manage.sh admin-password       # сменить пароль админа (все прежние входы сбросятся)
sudo bash manage.sh yoomoney-auth        # подключить/переподключить API ЮMoney
sudo bash manage.sh yoomoney-check       # проверить связь с ЮMoney и неоплаченные заказы
sudo bash manage.sh telegram             # подключить платёжного Telegram-бота
sudo bash manage.sh bot-logs             # журнал бота
sudo bash manage.sh add-file Kolca.exe   # выложить файл для покупателей «Навсегда» (.exe .apk .zip)
sudo bash manage.sh files                # что лежит в раздаче
sudo bash manage.sh stats                # пользователи, покупки, деньги
sudo bash manage.sh config               # заново пройти настройку (домен, цены, ЮMoney, карта)
sudo bash manage.sh logs                 # журнал сайта (выход — Ctrl+C)
sudo bash manage.sh status | restart | stop | start
sudo bash manage.sh backup               # копия базы в ./backups
sudo bash manage.sh update               # обновиться из GitHub
```

Чтобы закинуть exe/apk со своего компьютера на сервер, выполните на компьютере `scp Kolca.exe root@IP_СЕРВЕРА:/root/`, затем на сервере: `sudo bash manage.sh add-file /root/Kolca.exe`.

## Работа по IP (без домена)

Сайт открывается по `http://IP_СЕРВЕРА`. Всё работает, включая оплату через ЮMoney: оплату проверяет сам сервер раз в минуту, а покупатель может нажать «Проверить оплату». Ограничения такие:
- **Нет HTTPS.** Сертификаты на голый IP не выдают, поэтому пароли и данные передаются без шифрования. Покупатели увидят в браузере «Не защищено».
- **HTTP-уведомления ЮMoney не работают**, потому что им нужен https. Это не страшно: оплата всё равно засчитается в течение минуты.
- **Redirect URI приложения ЮMoney.** Если ЮMoney не принимает `http://IP/yoomoney/oauth`, укажите `https://localhost/yoomoney/oauth`. При `yoomoney-auth` страница после «Разрешить» не откроется, просто скопируйте весь адрес из строки браузера (в нём есть `code=...`) и вставьте в терминал.

Когда появится домен, выполните `sudo bash manage.sh config` (или `duckdns`). HTTPS включится сам.

## Бесплатный домен DuckDNS

1. Откройте [duckdns.org](https://www.duckdns.org) и войдите через Google или GitHub.
2. Придумайте имя в поле «sub domain» и нажмите «add domain». Скопируйте **token** сверху страницы.
3. На сервере выполните `sudo bash manage.sh duckdns` (или оставьте домен пустым при `install`) и введите имя и токен.

Сайт откроется на `https://имя.duckdns.org`, HTTPS-сертификат выпустится сам. IP сервера обновляется у DuckDNS каждые 5 минут, на случай если он сменится. Если домен меняется после настройки ЮMoney, поправьте Redirect URI приложения ЮMoney и выполните `yoomoney-auth` ещё раз.

## Как подключить ЮMoney

Оплату проверяет **сервер**, а не сайт. Браузеру покупателя и содержимому уведомлений сайт не доверяет. Сервер сам делает защищённый запрос к API ЮMoney: HTTPS с проверкой сертификата и токен доступа в заголовке. Он смотрит историю операций кошелька и ищет поступление с номером заказа. Доступ открывается, только если ЮMoney подтвердил операцию со статусом «успешно» на полную сумму (за вычетом комиссии ЮMoney). Одна операция засчитывается только один раз.

1. Заведите кошелёк на [yoomoney.ru](https://yoomoney.ru) и пройдите идентификацию: без неё карты почти не принимаются.
2. Зарегистрируйте приложение на [yoomoney.ru/myservices/new](https://yoomoney.ru/myservices/new). В поле **Redirect URI** укажите `https://ВАШ_ДОМЕН/yoomoney/oauth`. Галочку «Проверять подлинность приложения (client_secret)» лучше включить. Сохраните **client_id** (и client_secret).
3. Выполните `sudo bash manage.sh config` и впишите номер кошелька, client_id и client_secret.
4. Выполните `sudo bash manage.sh yoomoney-auth`. В терминале появится ссылка: откройте её (можно на телефоне), войдите в ЮMoney и нажмите «Разрешить». Сайт покажет код, вставьте его в терминал. Если страница не открылась, вставьте целиком адрес из строки браузера. Токен сохранится в базе на сервере, а не в файлах.
5. Проверьте связь: `sudo bash manage.sh yoomoney-check`.

Фоновая задача на сервере проверяет неоплаченные заказы раз в минуту, а покупатель может нажать «Проверить оплату» сам. Чтобы деньги зачислялись за секунды, включите **HTTP-уведомления**: Настройки → HTTP-уведомления, адрес `https://ВАШ_ДОМЕН/webhooks/yoomoney`, затем впишите секрет через `config`. Уведомление служит только сигналом «проверь сейчас»: даже поддельное, оно ничего не откроет без подтверждения от API.

Пока API не подключён, ЮMoney на сайте не предлагается (в админке будет предупреждение), а перевод на карту работает как обычно.

**Налоги.** Если продаёте как физлицо, оформите самозанятость в приложении «Мой налог»: это бесплатно, налог 4%, и чеки формируются там же.

## Платёжный Telegram-бот

Бот принимает оплату **звёздами Telegram**: покупатель покупает звёзды в самом Telegram за рубли и платит ими в боте. Паспорт, ИП и договоры с банками не нужны.

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя. Он пришлёт токен вида `123456:ABC...`.
2. Свой Telegram ID покажет бот [@userinfobot](https://t.me/userinfobot) — на него будут приходить уведомления об оплатах.
3. На сервере: `git pull` и `sudo bash manage.sh telegram` — впишите токен, курс звезды и свой ID.

Что умеет бот:

- привязка к аккаунту сайта одноразовой ссылкой (в «Аккаунте» кнопка «Привязать Telegram»; на странице цен появляется способ «Звёздами в Telegram-боте»);
- покупка «Месяц онлайн» и «Навсегда», пополнение баланса пакетами (`TG_TOPUP_PACKS`); цены в звёздах = цена в рублях / `TG_STAR_RUB`;
- оплата засчитывается только по подтверждению от Telegram, сумма и заказ сверяются с базой, повтор уведомления ничего не начисляет дважды;
- администратору приходит сообщение о каждой оплате; команда `/refund ID_ПЛАТЕЖА` возвращает звёзды и отменяет покупку;
- `/paysupport` и `/terms` — обязательные для оплаты звёздами команды.

Звёзды копятся на балансе бота. Вывести их можно через Fragment в TON (после 21 дня), а TON — продать за рубли.

## Админка

- Адрес секретный: `https://домен/admin-<случайные символы>/`. По адресу `/admin` ничего нет. Узнать его можно командой `admin-url`.
- Администратор один. Входа по логину нет, только пароль, который задаётся из терминала.
- После 5 неверных паролей с одного IP вход блокируется на 15 минут. Вход в админку и все действия пишутся в журнал с IP.
- Сессия админа привязана к IP и закрывается через 2 часа без действий. После смены пароля все входы сбрасываются.

Что можно делать в админке:
- **Пользователи.** Поиск, фильтры, статистика.
- **Доступ.** Добавить дни игры, выдать «Навсегда», снять доступ.
- **Баланс.** Начислить или списать рубли с комментарием.
- **Бан и разбан.** Заблокированного сразу выкидывает со всех устройств.
- **Разлогинить пользователя везде** и **удалить аккаунт.**
- **Оплаты.** Список покупок, кнопки «Подтвердить» и «Отклонить» для переводов на карту.
- **Файлы.** Загрузка и удаление exe/apk.
- **Журнал действий.**

## Безопасность

- Только HTTPS (Caddy, HSTS). Куки сессии с флагами Secure, HttpOnly и SameSite. Каждая форма защищена CSRF-токеном.
- Пароли хранятся только в виде хеша (scrypt). Перебор паролей ограничен: и для пользователей, и для админа, по IP и по почте.
- Заголовки Content-Security-Policy, X-Frame-Options, nosniff и Referrer-Policy. Обычный запрос ограничен 64 КБ, большие файлы принимаются только в загрузке админки.
- Игры и файлы отдаются только тем, у кого есть доступ. Прямые ссылки без входа не работают, выйти из папки загрузок нельзя.
- Оплату ЮMoney подтверждает сервер своим запросом к API ЮMoney (HTTPS, TLS 1.2+, токен OAuth). Ни браузер, ни уведомление не могут открыть доступ сами. Проверяется сумма, статус и номер заказа, одна операция засчитывается один раз. Токен хранится в базе на сервере.
- Контейнер сайта работает не от root, с файловой системой только для чтения, без привилегий и с лимитами памяти. Наружу открыт только Caddy.
- На сервере включены фаервол ufw и автообновления безопасности. Файл `.env` с секретами доступен только root.

Рекомендации: заходите на сервер по SSH-ключу, а вход по паролю отключите. Регулярно делайте `manage.sh backup`.

## Тексты и переводы

Переводы лежат в `tools_i18n_src.py`. После правки выполните `python3 tools_i18n_src.py`, затем `sudo bash manage.sh update`.
